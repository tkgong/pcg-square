# B200 run: PCG-output NTT designs on Cheddar's kernels (branch contention-cosim, commit faeb50d)

Repository: git@github.com:tkgong/pcg-square.git, branch `contention-cosim`, commit `faeb50d`.
Work in `GPU_baseline/cheddar`. Same toolchain as the previous B200 jobs (`job_cheddar_b200_all.sbatch`): CUDA 13.0 nvcc at
`$HOME/opt/cuda-13.0/bin/nvcc`, GPUNTT at `$HOME/.local/include/GPUNTT-1.0` and `$HOME/.local/lib64`. If your paths differ,
export `NVCC`, `GPUNTT_INC`, `GPUNTT_LIB` before `sbatch` (the scripts read them).

## 1. Submit

```bash
git fetch origin && git checkout contention-cosim && git reset --hard faeb50d
cd GPU_baseline/cheddar
sbatch job_cheddar_ole_b200.sbatch
```

The job (one B200, up to 10 h) runs two scripts:

1. `run_cheddar_ole.sh` with `DESIGNS=ole,ole_r,olep,olepb`, logN 20..24, batch 4/16/64, register caps 0/128/64. It builds
   `cheddar_bigN_bench.cu` per (logN, cap), sweeps the same P2/M1/B1/M2 space Cheddar gets, checks every output z against
   the merge NTT computed one product at a time, and APPENDS rows to `../results_b200/cheddar_bigN_b200.csv` (the Cheddar
   and four-step rows already there are kept). Designs produced: `ole`, `ole_t`, `ole_r`, `olep`, `olepb`.
2. `run_cheddar_interfere_ole.sh` with `BLOCKS=8,16,32,64,96,128`: the `ole` and `ole_t` victims at their best standalone
   config per logN beside the streaming, SPU-like row-burst and sleep-only aggressors, written to
   `../results_b200/cheddar_interfere_ole_b200.csv` and `.txt`.

## 2. Checks before reporting

- `../results_b200/cheddar_bigN_b200.csv`: rows with design `ole`, `ole_t`, `ole_r`, `olep`, `olepb` exist at every logN
  20..24 for batch 4, 16 and 64 (15 (logN, batch) cells each), and every such row has `mismatches` = 0. Count:
  `awk -F, '$3 ~ /^ole/ && $11 != 0' ../results_b200/cheddar_bigN_b200.csv | wc -l` must print 0.
- `../results_b200/cheddar_bigN_b200.txt` has the "PCG output" table (regenerated by `summarize_bigN.py b200`).
- `../results_b200/cheddar_interfere_ole_b200.txt` has rows for both victims at every logN and all three aggressor modes.
- The job log `cheddar_ole_b200_<jobid>.out` has no "bench exited with" lines. If a (logN, cap) run died, paste the lines
  around it instead of re-running blindly.
