Unified processing unit: the SPU reconfigured to also run AiM's BF16 functions (bf16.v, arx.v, pu.v; one source, three
configurations).  Yosys 0.71+, NanGate 45 nm open cell library (typical), clock gates, ABC mapping.
The AiM-function unit is a reconstruction from the public description (16 BF16 multipliers + adder tree per unit, MAC,
element-wise multiply and add) on an HBM-PIM-style frame (2 x 8 x 256 b registers, 16 x 16 b scalars, 32-instruction
memory); it is not a vendor netlist.  The SPU follows PIM/docs/pim_isa_assembly.md (dual issue, 16 x 256 b + scalars).
Not in the RTL: AiM's activation-function table, the last-level fused CONVERT micro-sequence (its mod-ALU hooks are
in and tested single-stepped).  Areas are post-mapping cell area, no placement, no memory compiler.
